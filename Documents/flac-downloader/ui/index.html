SpotiFlac Integration
Anonymous proxy services are read from ~/.spotiflac/ and used automatically when DRM is detected. No Qobuz account is required.
Download Quality
Network & Privacy
What leaves your machine:
 • Odesli (api.odesli.co) — source URL, only when DRM fallback triggers
 • Proxy services — numeric Qobuz track ID only, when DRM fallback triggers
 • MusicBrainz — title + artist for ISRC lookup only
 • yt-dlp — requests go directly to the source site

All connections use HTTPS. No account credentials are required or stored.
No analytics or telemetry is collected by this app.
Troubleshooting
Filenames
yt-dlp template syntax. Common fields: %(title)s, %(artist)s, %(uploader)s, %(album)s, %(track_number)02d, %(upload_date)s. Use / to make subfolders. The file extension is added automatically.
Downloads
Only used when “Download subtitles” is ticked on the Video tab.
Streams arrive as hundreds of small fragments; fetching a few at once is much faster, but too many can get you rate-limited.
SponsorBlock
Uses the community SponsorBlock database to cut the selected segments out of the file. Sends the video ID to sponsor.ajay.app when enabled.
Plays the system sound and flashes the taskbar once the whole queue is done, so you can leave it running.
Saves error details to a file so a failing download can be diagnosed. Off by default; leave it off unless you're chasing a problem.
Site sign-in
Some sites only serve video to a signed-in or age-confirmed visitor. Paste any URL from the site and a real browser window opens — sign in there, then close it, and this app will reuse that session.
Saved sessions are stored unencrypted on this PC and are as sensitive as your password. Forget them when you're done.
